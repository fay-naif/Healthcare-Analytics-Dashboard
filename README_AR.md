# لوحة تحليل بيانات الرعاية الصحية

لوحة Power BI من ثلاث صفحات تحلل الزيارات والفواتير وتدفق المرضى في ثمانية مراكز طبية في المملكة العربية السعودية خلال الفترة 2023–2025.

[English README](README.md)

## الأهداف

- متابعة حجم العمل: الزيارات، المرضى، المستشفيات، الأطباء.
- معرفة مصادر الإيرادات وأين تضيع المبالغ غير المحصّلة.
- قياس أوقات الانتظار، واستجابة الطوارئ مقارنة بهدف 30 دقيقة، ونسب التنويم والتحويل.
- مقارنة الضغط على الأسرّة بين المستشفيات (التنويم لكل سرير).
- مقارنة 2025 بـ 2024 لكل المؤشرات الرئيسية.

## البيانات

ملف `data/Healthcare_Analytics_Clean_30000.xlsx`: بيانات محاكاة (synthetic) وليست سجلات طبية حقيقية، فيها 30,000 زيارة و 8,000 مريض و 8 منشآت و 120 طبيب، موزعة على ست أوراق (Visits, Billing, Patients, Facilities, Providers, Services) وتم ربطها في Power Query في جدول واحد.

## الصفحات

- **Overview**: الغلاف والأرقام الرئيسية.
- **Revenue**: الفواتير والتحصيل ونسبة التحصيل والمبالغ غير المحصّلة حسب الخدمة، والمؤمَّن مقابل الدفع الذاتي.
- **Patient Flow**: متوسط الانتظار وتوزيعه، الزيارات فوق 90 دقيقة، الطوارئ خلال 30 دقيقة، التنويم والتحويل، والتنويم لكل سرير.

## الأدوات

Power BI · DAX · Power Query · Excel

## طريقة الفتح

1. نزّل المستودع (Clone أو Download ZIP) واستخرج الملفات.
2. افتح `dashboard/Healthcare_Story.pbip` في Power BI Desktop.
3. اضغط **Home ← Refresh**، البيانات مدمجة داخل النموذج فيشتغل مباشرة.
4. اختياري: للقراءة من ملف الإكسل مباشرة: **Transform data ← Edit parameters ← FilePath** وضع المسار الكامل للملف ثم Refresh.
